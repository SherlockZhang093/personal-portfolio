# Harvest · AI NPC 任务设计

[返回作品集](../README.md) · [Harvest 源码](https://github.com/SherlockZhang093/harvest2)

目标是让玩家用自然语言分配农活，让 NPC 在资源、身体状态和时间约束下执行。当前依据已有设计图和作者介绍，尚未核实源码与录像版本。

## 系统分工

| 阶段 | 流程图表达的设计 |
| --- | --- |
| 输入 | 玩家原话、NPC 状态、农田环境、背包与进度 |
| 决策 | 输出目标、任务类型、优先级和台词 |
| 校验 | 检查格式、资源、目标与时效；无效指令不修改游戏事实 |
| 调度 | 当前工作、待办、暂停任务与持续目标 |
| 执行 | 寻路与行为返回成功、失败或取消 |
| 反馈 | 更新世界状态和任务进度 |
